0 导学：课程结构与界面

一句话记住：这门课分基础篇 / 进阶篇 / 实战篇三块，学之前先把四个面板认全，把「媒体丢失、格式不支持、卡顿」三个常见坑填掉。

课程结构

剪映，课程分三个部分：

  • 基础篇：界面、流程、口播、混剪、音效、导出
  • 进阶篇：关键帧、变速、抠像、调色
  • 实战篇：包装复刻、跟踪、多机位、结构理论

界面：从左到右四个面板

默认布局从左到右排列，也可以在右上角切换布局：

面板 作用
素材面板 添加素材和各种效果工具
播放器面板 预览画面

时间线面板 排列、剪辑所有轨道

1 十分钟走通专业剪辑全流程

一句话记住：这条片子的全流程就是 导入 → 拖上时间线 → 排/切/删 → 踩节拍对齐 → 导出；先有「轨道」概念，再谈技巧。

步骤一：新建工程、导入素材

  • 新建工程界面先导入素材。
  • 还有官方素材库，可以随意挑选、收藏。

步骤二：把素材放上时间线

  • 点素材的加号或直接拖拽，都能加到时间线。
  • 播放头以帧为单位——剪辑的最小单位就是帧。

关键概念：主轨与辅轨

  • 在添加第二个素材之前，先在参数面板右下角打开「自由层级」。
  • 上下维度 = 画中画格式。
  • 最下面一层叫主轨，往上的其他轨道叫辅轨。
  • 主轨有磁吸功能。

基础操作只有四件事：导入、分割、删除、排列。所谓剪辑，本质就是一个「素材排列拼接」的过程。

BGM 与踩节拍

  • BGM 背景音乐非常重要。
  • 音频一般在主轨下方，最左边有音乐符号作区分。

操作：

  1. 选中音频轨道；
  2. 在时间线左上方找到标记按钮，点「踩节拍」；
  3. 踩好后，把每一段视频的开头或结尾拖动到最近的标记点上对齐。

预览卡顿的两个应急手段

  • 点视频播放器下面的清晰度按钮降低预览画质；
  • 点轨道空白处 → 草稿参数面板的「修改」→ 性能 → 代理调低。

首次导出参数（参考）

项目 取值
分辨率 1080p – 4K
格式 MP4
帧率 60
视频码率 推荐 / 更高
视频编码 HEVC
音频质量 PCM 无损
音频采样率 48000 Hz

这套是「第一节课的通用参考值」。正式交付时以第 5 课的导出逻辑和平台推荐表为准，别两处混用。

2 口播精剪与 A-Roll / B-Roll 协同

一句话记住：口播片 = 先把话修干净（智能剪口播）→ 再用 B-Roll 盖画面 → 最后补字幕和 BGM。声音是主线，画面是补丁。

开工前的环境设置

点右上角「全局设置」：

  • 草稿：修改「草稿位置」、「素材下载位置」；
  • 性能：代理模式设为「新建草稿时默认开启」。

第一步：看清口播的问题

未剪辑的口播一定有大量气口、啰嗦、重复，以及个人口癖。

  • 点时间线右上角的三个点 → 打开「轨道调节」→ 把轨道音频占比调到 60% 左右，看波形判断气口。
  • 音频全平的部分，大概率就是卡顿或没正常发声的部分。

第二步：智能剪口播（语义化剪辑）

  1. 导入口播视频；
  2. 右键素材 → 菜单里点「智能剪口播工具」；
  3. 左侧生成对应文字稿，直接在稿子里删掉不要的词、不要的停顿；
  4. 视频轨道会同步剪辑、同步删除。

遇到「两个气口挨太近」听起来很怪：把两段分隔开，然后为前后两个音频段落各拉一下音频轨道的小把手，取房间安静状态的底噪，垫到下面填空。

第三步：A-Roll 与 B-Roll

  • A-Roll：一般是主轨道的信息（讲话、叙事主线）。
  • B-Roll：辅轨道素材（点时间线左上角可新建时间线，用双时间线）。

操作逻辑：播放 A-Roll，听到 A-Roll 里提到的内容，就去上面的时间线里捞对应画面，裁掉前后没用的段落，取中间可用的拉到 A-Roll 的辅轨。

例：口播里说「这个全新的柑橘色，有点偏绿」→ 在 B-Roll 里找到展示该颜色的素材，取中间可用段落，铺到辅轨。

B-Roll 与声音的实操经验（逐条对照）

  1. 对齐口播节奏：B-Roll 的切换点尽可能对齐说话的重音/节奏。
  2. 宁长勿短：B-Roll 太短、话没说完就切走，会「漏字」，让观众跳出你想表达的感觉——最好的解法是换一个更长的 B-Roll。
  3. 成组使用：B-Roll 通常按「镜头组」添加——同一内容、不同景别、不同角度的几个镜头组合在一起。
  4. 用放大规避断点：中间有 A-Roll 分隔时，可以用「放大」把卡顿的镜头藏掉。
  5. 不重复：一条片子里不要有重复的 B-Roll，尽量用不同的素材。
  6. B-Roll 一般无声：同一轨道里把音频轨道关掉。
  7. 声音优先在前期解决：最理想是前期把该录的话全录完。剪完气口后如果缺一句话，时间线右上角有录音功能可用——但那些功能没必要开，用自然的原声最好。
  8. 响度统一：音量不统一时，选中所有音频片段 → 右上角参数面板「响度统一」。
  9. 前期一个小问题，胜过后期十个补救。
  10. 麦克风套只袜子可以防喷麦。
  11. 一定戴耳机：很多问题其实是声道问题，在音频参数面板的「声道配置」里检查。
  12. 字幕先于 BGM（见下）。

第四步：先识别字幕，再加 BGM

  1. 左上角素材面板 → 字幕 → 自动识别；
  2. 不动任何设置，直接点开始识别，生成一排字幕轨道；
  3. 字幕默认互相关联——调好一段的参数，其他字幕会同步调整；
  4. 位置：视频中心下方；字体：简约黑体；同时打开阴影效果。

阴影参数（原课推荐值）：

参数 数值
不透明度 60%
模糊度 7%
距离 5
角度 -45°
  • 可以用图片素材里的「横屏安全区」当参考图，判断字幕位置是否安全。
  • 调好大小位置后，从头播放检查一遍错别字，并把所有字幕拉长，保证收尾衔接不闪断。

第五步：最后注入灵魂——BGM

至此，一条标准口播片的完整链路：素材管理 → 口播粗剪 → B-Roll 叠加 → 多轨道编排 → 字幕识别 → 导出。

3 混剪节奏与蒙太奇逻辑

一句话记住：没有 A-Roll 的混剪，靠景别搭骨架、音乐定节奏；节奏不能让人猜到下一拍，所以要会「切分节拍」，再往上叠蒙太奇。

混剪的起点：先分类，再搭框架

全是 B-Roll、没有 A-Roll 时，没有台词当主线，就必须有意识地挖掘素材特征，主动搭建剪辑框架。

没有头绪时，按景别分类：

  • 远景：展示宏大场景
  • 中景：突出人物动作
  • 特写：捕捉细微表情

剪辑中通过景别的跳跃和切换，构建基础的视觉层次。

剪辑的结构模式和音乐类似：镜头拼接从平缓过渡到高潮，再逐渐减弱直到柔和，最后汇合成一个重大的结束与终结。

顺序问题：音乐先行，还是景别先行？

  • 景别决定观众看什么；
  • BGM 决定用什么节奏去看。

所以：在搭景别框架之前，先找一段合适的音乐，确定节奏主线。

操作：导入音频 → 用踩节拍工具踩点。针对音乐平稳的开头，先用「节拍 1」匹配舒缓基调。

音乐开头常有一段情绪铺垫（只有弦乐、还没有鼓点），这时镜头要选镜头语言平缓、没有剧烈位移的空镜（纯粹描绘氛围的空镜），来缓解画面张力。

双时间线剪辑法

建议沿用第 2 课的双时间线思路：

  • 时间线 2：素材（B-Roll）
  • 时间线 1：BGM

这是为了观众的节奏感、也为后续的节奏爆发蓄力，最稳妥的编排逻辑。

景别递进：从广阔到具体

遵循景别递进做空间叙事：

  1. 远景：交代氛围的大远景
  2. 中景：交代环境关系
  3. 近景 / 特写：突出人物情绪、核心主体的细节

单一套路用多了会单调，所以引入更进一步的镜头拼接思维。

匹配剪辑与蒙太奇

  • 匹配剪辑：镜头之间的衔接通常是导演和剪辑师设计出来的。比如从骨头切到宇宙飞船，靠的是相似的几何形状或运动轨迹做匹配。
  • 但它不只是把两个相似镜头接在一起这么简单。
  • 两个本无关系的镜头接到一起后，观众会自动脑补关联，创造 1+1 > 2 的效果——这就是蒙太奇（装配与组装）。
  • 蒙太奇是剪辑师控制情绪、引导观众思考的核心工具。掌握它，你就不只是拼接镜头，而是用镜头写文章。

打破预期：切分节拍

一直严格按节拍剪，节奏始终在观众预期内，观众就会预判到下一拍的时机。

切分节拍：在两个节拍之间插入一个新的节拍（高潮）。

  • 可以在不该出现剪辑点的地方突然切一刀；
  • 也可以在重音到来之前提前抢一拍。

转场预设

  • 位置：左上角素材面板 → 光效 → 炫光转场，拖到两个素材的剪辑点处。
  • 添加后点击转场本身，右上角参数面板可调整时长，也可点下面的「应用全部」。
  • 原则：在保持画面转换流畅的前提下，尽量选风格简约的效果。

特效：调味料，不是主菜

想在剪辑点之外提示画面质感时，用特效。

特效可以理解为：已经被预设好、可以直接叠加在画面里、样式丰富的动态滤镜。

  • 画面特效
  • 人物特效

特效只是调味料，从来不是视频的主菜。需要在强调情绪、增强氛围的关键点上稍微点缀，不要每个镜头都往上堆。真正让画面出彩的是素材本身 + 组接素材的逻辑 + 本身的节奏。

4 听觉塑造：音乐处理与音效设计

一句话记住：声音能提前建场（J-Cut）、也能留场（L-Cut）；音效要参与叙事，而不是随手铺满。

处理过长的 BGM

  1. 找到副歌结束时的那个重拍（鼓点最响的一下），切开；
  2. 把后面那一段音频拉到最低；
  3. 选中这两段音频，按 Alt + G 封装成音频复合片段。

目的是保持听感的纯净，让音乐自然收在重拍上。

环境音效：从画面联想

  • 观察画面，同步联想「这一段地方可能有什么声音」——比如海浪、风声、火焰。
  • 常见音效剪映素材库都有：左上角素材面板 → 音频工具 → 音效库 → 搜索框直接搜。

J-Cut 与 L-Cut

  • J-Cut：声音先行，画面后出。 让声音提前 2–3 秒、并给一个渐入效果——画面还没出来，海浪已经响起，观众脑海里已自动构建海边场景的预期，等画面出来一切都很自然。
  • L-Cut：画面消失，音乐正常播放。（声音留住、画面先走）

特殊设计音效

光有环境音，画面冲击力还不够；想进一步强化视觉张力，就用设计过的特殊音效。

  • 不只用在开场和转场，还能强化动作节奏，甚至构建超现实氛围；
  • 例：画面是缓慢推进的空镜时，加低音轰鸣。

音效不只在配音，它同时参与叙事。你添加的每一个音效都应该认真斟酌，否则很可能适得其反、影响观感。音效的添加与设计需要长期练习。

音效素材的来源

  1. 新手首选：剪映自带音效库，充分利用。
  2. 实在找不到，可以试剪映自带的 AI 音效。
  3. 也可以自己录声音，导入剪映后改一下倍速和音调。

国外商用免版权音乐站（专业音效/配乐资源）：

网站 特点
Musicbed 高品质影视向配乐，偏大气、抒情，适合短片、宣传片
Artlist 热门订阅制 BGM 平台，歌曲量大，视频创作者常用

5 最终交付与导出管理

一句话记住：糊不糊、大不大，只看分辨率 / 帧率 / 码率三个参数；而封面、命名、工程文件夹决定了你半年后还能不能找回这条片子。

问题引入

花好几天剪出来的片子，糊得连字幕都看不清，或者文件大得发不出去，只能再压一遍——发朋友圈、抖音、小红书都难受。

封面

  • 默认情况下剪映会自动提取视频第一帧作封面，但第一帧往往是黑场。
  • 点视频封面下方的「前往选择」，手动挑一个静帧：
    • 人物表情最自然的瞬间，或景色最美的一刻；
    • 一定要有张力、要简洁。
  • 选好之后还可以加标题、加包装（编辑封面）。
  • 也可以自己做封面再导入（例如用豆包模仿 B 站封面风格）。

命名规范

示例：2026-01-10_混剪教学_4K_成片1_抖音

格式：日期 + 片名 + 分辨率 + 视频版本 + 平台

为什么要这样命名：

  • 一条片子一定会反复修改、导出好几个版本（抖音版、朋友圈版、给客户看的小样）；
  • 从导出第一个文件开始就养成习惯，哪怕只给自己看；
  • 一眼就能看出：哪天做的、什么分辨率、成片还是过程稿、第几个版本、发哪个平台。

决定清晰度与体积的三个参数

一个视频导出后是否清晰、文件大小是否合理，本质上只受三个关键参数影响。

1. 分辨率

  • 指视频的清晰度，即里面的像素数量。
  • 上限由原始素材决定，一般保持原分辨率。
  • ⚠️ 素材本身就是 1080P，强行拉到 4K 不会变清晰，盲目导出高分辨率除了体积臃肿还会有其他问题。
  • 原文另列出两个「智能」选项：智能分辨率、智能补帧。

2. 帧率

  • 决定画面的流畅度和综合播放的清晰度；剪辑中可剪的最小单位就是一帧（一张图片）。
  • 指视频中每秒有多少帧画面。
  • 常见取值：
帧率 适用场景
24 帧 电影感
25 帧 中国广播电视标准
30 帧 普通标准视频
60 帧 运动画面
  • 一般跟原视频保持一致。
  • ⚠️ 不建议使用 AI 自动补帧：AI 技术只作为单段素材的补救手段——某个素材本身清晰度不足、帧率和其他素材没法匹配时再用。不要指望它取代前期拍摄。

3. 编码码率

  • 指视频中保存的信息密度，即每一秒视频软件分配了多少算力和数据量去压缩画面。
  • 码率越高 → 数据量越大、需要压掉的东西越少 → 细节保留更多（树叶边缘更清晰、远处纹理更清楚），代价是文件变大。
  • 码率越低 → 数据量越小、文件越小 → 画面开始丢东西：模糊、马赛克、色块缺失。
  • 码率并不是越高越好；一般选「推荐」，让剪映自己选合适码率。

6 运动控制：关键帧与曲线运动

一句话记住：关键帧 = 给某个参数设起点和终点，中间交给软件补间；补出来的是匀速直线，想自然就得改曲线，而且相关参数的曲线必须一起改。

前置：素材的基础参数

先把素材拖进时间线，右键 → 基础调整：定格、倒放、旋转、镜像、裁剪等。这些是比较好上手的基础属性。

更复杂的参数在右上角参数面板里（选中素材后出现）：

  • 缩放：也可以直接拖拽素材边框来缩放
  • 位置：按住画面本身拖动来改变位置

通常片段与片段之间的参数没有关联。想同时改变多个片段的参数，需要全选后再去右上角参数面板调整。

调整这些参数后，片段就会应用并固定下来。但进阶剪辑中我们要让画面动起来（画面缓缓推进、文字从屏幕外飞进来），这就需要关键帧。

关键帧的本质

给素材的某个参数，设置一个起点和一个终点，让软件按时间顺序帮我们计算中间的变化过程。

  • 当同一个参数上有两个及以上不同数值的关键帧时，软件会读取这两个关键帧，随时间变化把中间每一帧都算出来；
  • 起点到终点的变化，就以视觉方式呈现在播放器里；
  • 所有中间位置都是软件帮忙补全的，这个过程叫 **补间动画**；
  • 选中素材后，右上角每个可调参数后面都有一个菱形按钮——这意味着任何参数都能随时间变化，进一步组合就能做出复杂动画。

案例：手机推近效果

把素材拖到时间线，添加关键帧前先想清楚这个放大动画：

要素 内容
起点关键帧 从哪里开始（举起手机的那一刻：缩放 + 位置）
终点关键帧 在哪里结束，终点这一帧把画面放到合适构图（手机充满画面这一帧）
涉及参数 位置、缩放、旋转——注意每一个都要打上关键帧

判断有没有打上：看右边参数面板，实心 = 有关键帧，空心 = 没有关键帧。

常见错误：播放时出现「先移动后放大」或「先放大后移动」，说明关键帧错位了。按住 Ctrl + 滚轮 放大时间线，仔细检查关键帧位置。

关键帧曲线（让运动有力量感）

关键帧只负责记录参数信息，软件生成的动画只是两个关键帧之间的线性运动；这个线性的速度，没办法通过调整关键帧数值本身来改变。

操作：

  1. 右键素材片段 → 关键帧变速曲线（快捷键 Alt + K）；
  2. 关键帧轨道展开，出现三条曲线（横轴是时间）：
    1. 缩放
    2. X 轴
    3. Y 轴
  3. 默认是线性的，大脑看来不自然。为了更自然：
    • 走 加速 → 减速，就是 S 形曲线，这是曲线动画的原理；
    • 点这根缩放参数的线 → 右上角按钮 → 选剪映准备好的预设 → 点「二次方缓动 S 形」。
  4. ⚠️ 三根线只动了一根，动画就会出现明显错位——三个参数节奏不统一就导致动作脱节。
  5. 想让画面协调，必须让所有相关参数的曲线保持一致：分别点 X 轴、Y 轴，也用上同样的「二次方缓动」。

关键帧的本质：给静态的参数注入一个时间上的维度。有了它，才能精确控制任何一个效果的开始、结束，以及中间的变化节奏。

关键帧这个东西必须多练、多试、多调。而且这门技术不太可能随时间消亡——哪怕真有 AI 生成的内容，关键帧这个工具大概还是会用到。

7 动态节奏：曲线变速与素材帧率

一句话记住：变速不是被动调速度，而是主动操控观众注意力；慢放卡顿靠补帧只能补救，真正丝滑的前提是前期拍高帧率。

为什么调速度

画面节奏忽快忽慢，紧张时突然加速、震撼时瞬间慢放——片子的情绪是被速度牵着走的（运动里的爆发瞬间、旅拍的转场衔接、卡点混剪）。

作为剪辑师，要做的不是被动调整播放速度，而是主动利用速度去控制观众的注意力：该快时让节奏飞起来，该慢时突然慢下来让画面有冲击力。快慢之间的切换，就是剪辑师掌控时间的方式——操控时间的能力。

基础变速

  1. 时间线上点中片段；
  2. 右上角参数面板找到第三个选项「变速」；
  3. 素材片段左右两侧出现一对白色手柄，拖拽即可：
    • 拖短 = 提高倍速 = 快放
    • 拖长 = 降低倍速 = 慢放
  4. 拉动时，右上角参数面板里的变速数值会同步变化。

慢放为什么卡？怎么补？

  • 慢放到 0.1 倍速时，画面明显卡顿、丢帧；慢放倍率越大，卡顿越明显。
  • 原因：变速时素材内部发生了重复帧，或丢弃部分帧来填补空白。

剪映的解决方案：智能补帧（用 AI 生成新帧填补帧间空白），点开有两个选项：

方式 原理 优缺点
帧融合 把前后两帧画面叠加、模糊混合，补上一个过渡 处理速度快；缺陷明显——重影、破碎感
光流法 分析画面里物体运动轨迹，算出一张「理论上应该存在」的中间帧插进去 速度慢，但效果更好、运动更流畅

⚠️ 但必须清楚：

  • 两种补帧都是后期算法造出来的画面，再怎么补也达不到原生高帧率拍摄的自然感，只是补救策略，不建议过度依赖它做强行的慢动作。
  • 想在后期做丝滑升格，最好的方法是前期就拍高帧率（60 帧、120 帧甚至更高），这样后期有足够多的原始画面，放慢好几倍依然流畅。
  • 变速效果的好坏高度依赖素材本身质量：高帧率素材慢放丝滑，普通素材慢放容易卡顿。
  • 最佳做法：前期拍 60 帧或 120 帧 + 后期配合光流法。

什么时候该用变速

1. 艺术化处理

  • 前期高帧率拍摄，后期人为慢放 → 丝滑的升格效果（空翻、滑雪）；
  • 把普通素材加速模拟延时摄影的时间流逝（日出、日落）；
  • 目的是让画面本身更有表现力。

2. 空隙填补

  • 剪辑编排得差不多了，但这段素材离下个转场就差 1–2 秒，或多 1–2 秒；
  • 直接点变速拖拽两侧小手柄，拉满空隙长度即可（匀速变化）。

整段素材从头到尾只有一个速度，看起来就不怎么专业 → 所以要用曲线变速。

曲线变速

应用场景：在场景转换的位置把素材速度变快，加速瞬间观众注意力被速度变化吸引，视觉上有种「嗖」一下被拽过去的感觉；等速度恢复正常时，画面已经切到下一个场景了。

简单说：让视频想什么时候快就快，想什么时候慢就慢。

对比理解：关键帧曲线控制的是位置、缩放这些空间参数；曲线变速控制的是时间本身的速度。

操作：时间线点中素材 → 右上角参数面板 → 变速 → 曲线变速 → 自定义曲线，出现变速预览窗口：

元素 含义
横轴 视频的播放时间
白色竖线 对应时间线上的播放头
中间带三组把手的线 就是变速曲线
线上的小把手 素材片段两侧的变速把手，可在片段之间自由调整，把片段切分并变速（向上拖加速，向下拖减速）

上图即「加速 → 匀速 → 减速」的变速转场效果。

动作变速：重构画面重心

例：滑雪素材。目标是通过改变时间流速，强化雪墙喷发的视觉冲击力。

  1. 先定位素材中动作的顶点——滑雪者切入雪地、雪墙喷发到最后最高点的那一帧，把它作为速度变化的转折中心；
  2. 手动添加关键帧：在动作顶点之前把曲线向上拉高，实现快速推进；
  3. 在雪墙完全炸裂的瞬间，把曲线向下拉到 0.3 倍速，甚至 0.1 倍超慢动作；
  4. 这种极快 → 极慢的剧烈反差，就是想要的效果。

逻辑：快节奏负责制造动能；随后慢节奏迫使观众的视觉焦点停留在雪花破碎的细节上，从而成倍放大画面的震撼感。

剪映变速关键帧的调整逻辑，多试一试手感就有了。

变速卡点

画面跟着音乐鼓点忽快忽慢，每一拍都卡得刚刚好——手动做非常麻烦。

操作：导入素材 → 添加一段 BGM → 点击素材片段 → 变速 → 最后一个「变速卡点」→ 选一个喜欢的预设效果。

变速是剪辑中非常常用、也特别出效果的工具，但用得太多会审美疲劳。最重要的一点：在满足故事性的前提下合理运用，该快的时候快、该慢的时候慢，让速度真正为内容服务。

8 空间重组：全套抠像工具

一句话记住：抠像是一整套工具协作——智能抠像（AI 轮廓）/ 自定义抠像（手涂）/ 色度抠图（抠颜色）/ 蒙版（抠范围）/ 混合模式（抠亮暗），不同素材用不同工具，不同效果用不同组合。

剪映的两大优势：字幕识别、抠像。

一键抠人的智能抠像、处理发丝边缘的自定义抠像、绿幕素材的色度抠图，最后还有蒙版、混合模式。

开工前：默认开启自由层级

剪映主页 → 全局设置 → 「剪辑参数」里找到并勾选「新建草稿时默认打开自由层级」。这样以后新建草稿，自由层级默认都是开的。

抠像需要一个主体素材。点素材片段 → 右上角参数面板里找到「抠像」。

8.1 智能抠像

  • 剪映自动识别画面中的人物主体，抠出后背景变透明。
  • 抠完先别急着操作，先检查精准度：
    • 点时间线上的预览图标，或按快捷键 S，激活预览轴功能；
    • 鼠标会变成一个可自由拖动的播放头，能直观看到有没有残留背景、有没有把不该抠的抠掉。
  • 如果出现识别不精准（人物边缘有残留、有些地方没抠干净），就要用自定义抠像。

8.2 自定义抠像

  • 光标自动变成一支画笔，像画画一样在要抠出的物体上大致涂抹；
  • 笔画会自动识别物体边缘，帮你快速框定更大范围；
  • 大致范围选好后，可以进一步调整笔刷粗细，或换成普通画笔形态；
  • 涂多了就换智能橡皮擦；
  • 蓝色部分就是最后被抠出来的部分；
  • 调整满意后点击右下角「应用效果」，剪映会自动计算并跟踪物体在整个视频时间轴上的运动，最终抠干净并生成一个背景透明的独立图层。

最后再播放检查一遍，确定没有残留背景、也没有缺失的部分。

剪映的抠像虽然上手简单，但想做出有创意的效果，需要把不同工具组合起来用。

组合效果示例：

8.3 「三明治」：人物 + 文字 + 背景三层

口播评测时，每当提到关键信息，就把这一段素材单独切分出来：

  1. 复制一份相同素材，拖到辅轨，和下面的片段对齐同步播放；
  2. 点击辅轨上的素材进行抠像；
  3. 此时乍看没有区别——因为底层素材背景和上面的叠在一起了；
  4. 点击主轨上的素材片段，按快捷键 V 或右键禁用，把背景素材暂时关掉；
  5. 用预览轴 S 检查一遍抠图细节，确保没有问题；
  6. 添加一段文字轨道，把它的层级放到抠像层和背景层之间（中间层）；
  7. 调整文字大小和位置，加上剪映的入场、出场动画，选一个易读的字体。

成果：抠出的人物在最前面，文字在中间，背景在最后——像夹三明治一样，层次感一下就出来了。

动画参考：入场「随机上升」，出场「向下滑动」。

8.4 色度抠图（绿幕 / 蓝幕）

智能抠像和自定义抠图都是靠 AI 算法识别物体轮廓，大部分素材都能搞定；但遇到发丝飘逸、细节特别丰富的素材就不够用了。

色度抠图原理不同：它靠精准剔除某一种特定颜色，这种方式更稳定，适合影视制作中常见的蓝幕、绿幕。

操作：选中绿幕素材 → 拖到时间线 → 右上角「色度抠图」→ 会看到一个取色器（长得像小吸管）→ 把鼠标放到播放器上，光标变成吸管 → 在要抠掉的颜色上点一下，颜色瞬间扣除（点绿色背景，绿色消失、人物留下）。

抠不干净的原因：拍摄时绿幕难免有褶皱、明暗不匀、光线不均匀，导致背景出现深浅不一的绿色或噪点。默认阈值比较窄，只能扣掉与吸管颜色完全一致的部分，偏深偏浅的区域就残留了。→ 需要手动拉宽色度抠图的阈值。

参数 作用
强度 拉大则扣除的颜色范围变大，深一点的绿色也会被清掉
阴影 控制阴影区域的保留程度；拉大阴影，绿幕上的阴影区会被加重或保留（用来修复因打光不匀造成的残留痕迹）

⚠️ 阈值拉太满，画面就会漏。抠图时要一边观察画面变化，一边找刚刚好的平衡点。

边缘残留处理：

参数 作用
边缘羽化 拉大让抠出的物体边缘更柔和，与背景过渡更自然
边缘清除 专门对付顽固绿边，拉高会智能识别并去掉边缘残留的绿色

还是那句话：一边拉，一边观察，直到绿幕完全消失为止。

8.5 蒙版：只保留画面中的一块

问题：绿幕只有一小块，人物稍微一动、边缘就露馅了——能不能像剪纸一样只保留中间这一块？

蒙版：在一个画面中，只想显示其中的一个范围。

理解方式：中间剪了一个圆洞的卡纸挡在素材前面——透过圆洞的部分保留，被卡纸遮住的部分隐藏。这块卡纸就是核心逻辑，只不过剪辑里的卡纸更灵活多样。

操作：选中素材 → 右上角参数面板 → 蒙版工具 → 选一种形状（圆形、矩形等）来框选想保留或隐藏的画面范围。

8.6 混合模式：黑白素材的空间重组

想玩更酷炫的效果（合成烟雾、粒子消散），就要用混合模式。

操作：导入黑白素材 → 右上角参数面板 → 画面 → 基础 → 混合 → 逐一尝试不同混合模式预设，观察效果。

按预设分为三类：

分组 预设 作用
变亮组 颜色减淡、强光、变亮、滤色 剔除黑色部分，保留白色部分
变暗组 线性加深、正片叠底、颜色加深、变暗 剔除白色部分，保留黑色部分
叠加组 叠加、柔光 既不剔除亮部也不剔除暗部，让亮部更亮、暗部更暗地叠加，实现半透明效果

例：白底黑色颗粒的图，要去掉白底、保留黑色颗粒 → 用变暗组（线性加深、正片叠底、颜色加深、变暗）。

口诀：留白用变亮，留黑用变暗，融合用叠加。

小结

从最基础的智能抠像，到手动调整的自定义抠图，再到处理绿幕的色度抠图，最后还有蒙版和混合模式——抠像其实是一套完整的工具协作：不同的素材用不同的工具，不同的效果用不同的组合。

日常拍摄的素材，用智能抠像可能就完全够用；但想更进一步处理更专业、更多样的素材（绿幕、特效合成、创意转场），理解这些抠像工具的原理和操作就变得非常重要。

9 色彩科学：一级调色工具

一句话记住：好看不靠特效，靠色彩准确 + 明暗自然；调色本质只动三个值（亮度 / 饱和度 / 色相），而色轮是把这三个值最直观整合起来的工具，示波器则是你唯一可信的眼睛。

调色的两个基础

前八节课都在用工具打造画面的动态效果（关键帧让画面动起来、卡点打造节奏），但还有一个特别重要的维度：素材本身的样子。

什么样的画面第一眼看上去就是好看的？不取决于加了多少特效，而是两个基础：

  • 色彩是否准确
  • 明暗是否自然

想获得直觉上就很舒服的画面，需要用调节工具。调色是日积月累、逐步长进的功夫——不仅要会工具怎么用，还要对色彩本身有更进一步的感知。

起点：Log 灰片与 LUT

导入素材后发现画面灰灰的，那其实是 Log 灰片原始素材。

  • 这种灰灰的画面，比直出模式拍下来的彩色素材保留更多画面细节；大部分专业调色流程都基于灰片进行；
  • 但灰片确实会影响判断，所以需要色彩还原 LUT：通过查找画面里每一个像素的颜色、替换成预设好的另一个颜色——这也是它名字的由来：Look Up Table，颜色查找表。
  • ⚠️ 不同厂家用不同的 LUT 曲线，甚至同一厂家不同机型也不一样。使用 LUT 前要仔细辨别你的素材是用哪条 Log 曲线拍的。

两种使用方式：

  1. 选中素材 → 右上角参数面板 调整 → 基础 → LUT，直接作用在灰片上；
  2. 左上角「调节」里找一个 LUT 拖下来变成一条轨道，覆盖作用在素材片段之上。

用完 LUT、把灰片色彩还原后，就可以进入更多的自定义调节环节（也就是调色）。

调色的本质：三个数值

调整画面里每一颗像素的三个关键数值：

数值 决定
亮度 明暗
饱和度 浓淡
色相 到底是红、蓝还是绿

这三个是颜色的三个基本属性，剪映中所有调节工具本质上就是分别调整这三个维度。

位置：点击素材 → 右上角参数面板 → 调整。

基础调节：别只会拉「亮度」

  • 亮度滑块：往右画面变亮、往左变暗。但它控制的是画面整体，单纯拉动会把画面一起提亮/压暗——很容易让亮的地方过曝，或暗的地方死黑。
  • 所以一般用更细分的工具，分别调整亮部或暗部：
    • 高光：控制画面中高亮区域的明暗
    • 阴影：控制暗部的明暗
  • 饱和度：控制颜色的鲜艳程度。往右变浓，往左变淡，拉到最左就是黑白。
    • ⚠️ 新手最容易犯的错是把饱和度拉太满，觉得这样才好看。但高饱和度看久了非常容易腻，而且丢失层次感——适度的饱和度才是最舒服的。
  • 色相：决定颜色的种类（偏红还是偏蓝）。在 HSL 调节里可以单独选中某一种颜色再改它的色相。
    • 例：觉得画面里的绿色太扎眼，就单独调绿色的色相滑块往青的方向调。
  • 这三个参数结合在一起，就构成了调色的全部可能：色相、饱和度、亮度。

在专业调色中，会使用曲线、色轮这类能在一个面板里精准调节亮度、色相、饱和度的工具。这里推荐使用色轮。

色轮：把三个参数揉成一个直觉

动手前的关键前提：不要直接点击素材进行改变——那样不可逆，没法对比调色前后的效果。

推荐做法：点击素材面板上方的 调节 → 新建调节 → 自定义调节，拉到轨道上方叠加在素材上面（不去覆盖它），然后让这条叠加的调节轨道去作用不同的参数（比如色轮）。

单独新建一条调节轨道后，选中调节，再通过色轮修改。

点开色轮，有四个长得差不多的圆盘，分别对应画面中的四个区域：

  1. 阴影
  2. 中间调
  3. 高光
  4. 偏移

每个色轮上还有：饱和度滑轨、锚点（色相）、亮度滑块。

理解方式：每个色轮 = 一个把亮度、饱和度、色相三个参数整合到一起的调色控制中心，用非常直接的方式让你操控这三个维度。

操作 效果
拖动圆盘中心的锚点 该区域画面染上那个方向的颜色 → 控制色相（并带一定饱和度）
调左侧滑轨 与锚点配合，同时增强色相与饱和度；滑轨越高颜色越浓、饱和越强
拖右侧竖滑块 控制亮度；上拖变亮，下拖变暗

例：想让画面高光部分偏暖一点、亮一点，其他区域不变 → 在高光色轮里把锚点往橙红方向拖，再把右侧亮度滑块往上推一点，一步到位。

色轮的使用套路（原文给的起点）：

  • 阴影：往右下角一点
  • 中间调：往左侧一点
  • 高光：往橙色一点

色轮的魅力：它把三个独立参数用最直观的方式整合在一起。你不需要去想「我要加多少饱和度、多少色相」，只需凭直觉把锚点往想要的方向拖，画面变化一目了然。

而且四个色轮分别控制不同区域，可以非常精细地调整画面各部分：让阴影变冷、中间调保持自然、高光偏暖，组合起来能创造出非常丰富的画面层次。

示波器：不要靠眼睛猜

问题：调色时周边有灯、屏幕亮度、房间墙纸的色温，甚至今天戴的眼镜，都会干扰对颜色的感知。想要调色更专业精准，就需要一个能把饱和度、亮度、色相量化呈现的参考。

调色示波器：播放器面板右上角打开。

点开后播放器上出现三个不同样式的示波器，分别实时反映素材画面里的色相、饱和度、亮度。画面里每一个像素的亮度都会在波形图里显示成一个点。

  • 例：移动的灯光，波形图上代表灯光的亮点也会跟着移动；左对应画面左，右对应画面右，这些点堆叠起来就是波形。

三个图的读法：

图 看什么 怎么用
波形图 亮度分布 一眼看出哪里过曝、哪里欠曝。例：日出素材里太阳顶到了波形图顶部，说明该区域过曝、细节可能已丢失 → 精准压暗这部分，而不是凭感觉瞎猜
分量图 红、绿、蓝三通道亮度（逻辑同波形图） 画面里有灰色/白色物体时，三条线基本重合 = 白平衡准；某一条明显偏离 = 出现色偏
矢量图 饱和度 + 色相方向 圆代表饱和度本身，从圆心到边缘的距离 = 饱和度高低；星点飞出的方向 = 偏色方向（圆环一周不同角度对应不同色相）

色偏判断实例：

  • 画面偏蓝 → 分量图里蓝色通道的波形明显高于红、绿。

  • 画面偏黄 → 红色和绿色通道的波形一起压过蓝色。

不需要靠眼睛猜「这个画面是不是有点蓝」，直接看分量图，三条线一对比，偏色一目了然，再用色轮来调整。

修正色偏的操作：

  • 色偏比较简单时：只观察红绿蓝分量图就能调整——拨动偏移色轮中间的锚点，反向地远离那个颜色。
  • 但如果后期调节步骤出了错，画面偏向了一个不属于三原色的情况，只看分量图是判断不出来的。这时要同时观察示波器和最右边的矢量图。
  • 拉高画面整体饱和度，矢量图上代表像素的亮点会像星星一样从圆心向外扩散。

实用技巧：在色轮调节里找到偏移，把锚点按照星星扩散的相反方向调整，就能快速恢复对应色偏（例：往左下角拖）。

需要很多实践才能真正理解矢量图、分量图到底在做什么。调色不是一次就能精通的，需要很多次动手调。

建议：找一张特别喜欢的电影作品或静帧画面，导入剪映放在旁边当参考，对着它调整你的素材——尝试还原它的影调关系、色彩氛围、质感细节。这个过程会极大地训练你的观察力和色彩审美；通过自己的调整一步步接近心中理想的画面时，那种成就感是无与伦比的。

扩展：完整调色流程（实操记录）

观察分量图和波形图：

  • 1023 = 上限（最亮），0 = 下限（最暗）——两边都不能碰；
  • 把红绿蓝颜色铺满，但不能触及最暗、最亮。

一级调色：

  1. 加亮度、对比度；
  2. 增加阴影、增加高光，调整色温；
  3. 再调高光；
  4. 调整两个饱和度向上，暗部向上，再加一点黑；
  5. 一级调色完成 → 粘贴属性到下一个素材，再降一些阴影，继续调整。

HSL 分区控制：吸管吸取天空 → 增加饱和度、降一点亮度、降低色相。人脸皮肤、沙滩、土地都可以用 HSL 单独控制。

色轮：

  • 一级色轮：强度 50°，暗部往青色偏一点；
  • log 色轮：暗部往蓝色偏一点；「一起四轮」取消；
  • 中间调不动；高光往暖侧（唇侧）偏一点；中间往左侧调一点点；偏移不动；
  • 阴影亮度再沉一点；阴影饱和度稍微提高；高光饱和度稍微降下来；高光亮度增加一些。

滤镜：蓝橙 II，强度 30，染色——滤镜可以让整体更柔和一些。

分区调色：

  1. 加一个调整图层；
  2. 打开曲线，把亮度往下拉一点、降一点高光；
  3. 用蒙版钢笔大致把人框出来——现在是中间暗、两边亮；
  4. 蒙版点「反转」→ 人物亮、四周暗；
  5. 羽化拉到最大，扩展不用；
  6. 分割这个调整图层，按每个素材分别框选人物。

收尾：再重新加一个调节，增加锐化、清晰以及暗角；画面特效里加「电影感画幅」。

10 实操：快速复刻综艺包装

一句话记住：镜头时长由信息密度决定；想让观众一直看下去就搭「踩梯子」——每层都让观众对下一层有预期，但下一层又超出预期。

拉片：先用工具把成片拆开

可以把成片拖进时间线，用拉片工具「智能镜头分割」——这样能根据成片逐镜头对照，更好地复刻和对比画面。

智能镜头分割能节省大量拉片时间，每一个剪辑点都看得见，也不会出现手动剪辑时段落分不清的情况。

核心判断：镜头时长由信息密度决定

短视频的核心：信息少的可以快点切走，信息多的就得放长一些。

你必须让视频的节奏服务于你想传递的信息——观众到底要花多久，才能把屏幕上所有信息吸收完。

所以重点：化繁为简。这个视频的重点是「设备的预算」，大多数观众也只能看懂预算，别的东西只是辅助信息（用来体现设备很复杂）——那就只突出价格。

为什么这条片子不用转场

仔细看，这个视频没有使用转场：

  • 它本身的文字信息已经足够丰富，并且希望呈现的是递进式关系；
  • 递进关系 = 观众带着上一段画面的记忆，延续到下一段来增强理解；
  • 把设备一点一点背到身上、价格一层层递进，观众会更有预期看下去；
  • 如果加转场，一定程度上会打断观众「吸取信息的踩梯子关系」。

踩梯子

踩梯子：必须每一次都让观众对下一次抱有预期，但下一次又会超出观众的预期。这是特别核心的一点。

要让踩梯子有效，就要化繁为简：减少转场、舍弃音乐、弱化一切可能干扰踩梯子的东西，让观众的注意力全部集中在核心信息上——奔跑的人，和跳动的价格。

本片观众在意的只有两件事：Tim 在跑 和 价格。这种反差感、以及「这么多设备背在身上什么时候会砸在地上」的隐形心理预期，就是全部的钩子。

整体下来，这个视频的难度很低，更多的是心理上的游戏。

第一个镜头（1.2 秒）：只有一段简单信息——拿着手机跑，上面放一条粉丝的信息，只保留 1 秒左右。

  • 这样能保障视频开头的留存率被抓住；
  • 还交代了「视频中的人是谁、观众认不认识」。

跟踪文字：操作与避坑

跟踪原理：靠对比度和反差进行跟踪。

  • 框目标时不需完美无瑕地框住整个物体，只需要把跟踪框中心的十字标点锁在一个明显的、不易消失的物体上；
  • 关闭「透视」和「距离」，避免镜头前后移动时改变大小和透视效果。

流程：框目标 → 定特征点 → 开始跟踪

⚠️ 注意：

  • 素材越长，跟踪时间越久 → 必须先完成粗剪，再去添加文字和跟踪效果。
  • 文字排版：画面中可能出现多个追踪标签，要留意位置运动时不要撞在一起、不要和画面其他元素打架；该错开就错开、该留白就留白，始终保持清晰可读。
  • 字体选择：太有设计感的字体（明显的装饰线、非常规字体）会让本来就元素多的画面更杂乱。元素过多时选边缘平滑的非衬线、加粗字体。
  • 跟踪文字做好后先导出，不要继续往下做，原因有四：
    1. 相当于做了一次备份；
    2. 可以避免后期添加其他复杂效果时不小心误触或移动；
    3. 导出后跟踪效果已经渲染进视频，再怎么折腾都不会被影响；
    4. 不用复合片段的原因是——跟踪非常耗性能。

一句话记住：屏幕跟踪只作用于素材，所以要把文字轨先转成复合片段再跟踪；选范围要选画面中最大那一帧，跟踪完立刻重命名平面。

本节案例原型是「影视飓风运镜」——当你看了太多影视飓风、开始练手持手机运镜之后，正好用这段一镜到底的素材来练平面跟踪。

平面跟踪：在三维空间里，让文字去贴合物体的透视关系——要让文字真的长在物体上。

前置分析

导入素材后，先把成片导进来分析：这段一镜到底的视频，镜头在空间里穿梭，每经过一个关键物品，文字都会带着透视感贴上去——这就是平面跟踪。

开始实操前，建议先完整预览一遍，在脑子里标记出要处理的几个点位，再进入跟踪环节。

关键前提：文字轨道要先变成「素材」

剪映的屏幕跟踪只能作用于素材（图片或视频）。

→ 把文本轨道转化为复合片段，它就变成视频了，才能被跟踪。

  1. 先改一下文字参数（阴影等），让它更好看，保存预设；
  2. 退出复合片段前，把文本拉长一些；
  3. 点击复合片段 → 右上角参数面板 → 跟踪 → 平面跟踪；
  4. 先选中跟踪范围，再作用追踪。

注意事项（每条都是坑）

  • 选择跟踪范围时，要选画面中最大的那一帧；
  • 在复合片段中，尽量把文字轨道拉长；
  • 可以给文字添加入场效果；特效可用「色差故障」；
  • 给复合片段添加出场淡出效果；
  • 关闭等比后手动调节；
  • 追踪完成后，在当前追踪平面的选项里进行重命名；
  • ⚠️ 现版本限制：当你追踪的平面消失在画面中时，素材就会丢失跟踪目标，即便后面画面再出现，它也不会重新跟踪 → 所以最好在每段素材之后删除掉后面的复合片段；
  • 文字微调：不要尝试直接在复合片段上调整文字的高度/宽度 → 进入复合片段，选中文字，在右上角文字基础参数中找到「位置大小」，关闭等比缩放按钮，返回后分别调整缩放的高度和宽度，对比前后区别来恢复素材；
  • 如果出现文字跳出的情况，就重新调整一个跟踪。

预设：把常用包装存下来

在剪映中，除了文本参数外，像调节、已保存了多轨道的复合片段等工具，都可以一键快速设置为预设，下次直接调用。这非常方便，很适合保存一些固定的剪辑和包装。

12 实操：多机位采访剪辑

一句话记住：多机位只有三步——合板对齐 → 先剪内容 → 多机位切换；切换的唯一原则是镜头永远对准正在说话的人。

为什么用多机位

人物一来一回的对话，通常在同一场景的不同机位拍摄。为了提高效率、避免演员费两次事、避免拍摄多次出现穿帮，就用多机位的不同角度，对相同的空间做多角度同时拍摄。

第一步：多机位合板

本例准备了三段素材，分别是：Tim、Tim、Links（对应三个机位）。

拿到素材后，第一件事不是剪辑，而是多机位合板：把不同机位拍的素材按时间线完全对齐，让它们处在同一个时间轴上。

虽然拍摄时多机位同时开机，但每台机器的录制开始时间不可能完全一致。对齐方法：

  1. 音频波形对齐：根据同时发出的声音对齐（常用）；
  2. 时码器：在拍摄现场使用（很贵，不常用）。

手动操作：

  1. 选中所有不同机位的素材；
  2. 右键 →「新建多机位片段」，对齐方式选自动；
  3. 打开代理模式，保证剪辑流畅度。

此时播放器会变成两个窗口：

  • 左边窗口：可以同时预览所有机位素材；
  • 右边窗口：正常时间线的剪辑预览。

可以双击进入多机位片段，在里面快速对不同机位片段进行微调和初步调色。

第二步：多机位切换

剪映可以让它按线性播放的顺序，对三个机位进行实时切换。

采访视频最重要的原则：将镜头对准正在说话的人。

  • 把鼠标移到左边的多机位窗口，鼠标会变成剃刀图标；
  • 点一下想要的画面，时间线上就会自动切一刀，同时机位切过去；
  • 切错了怎么办：选中需要更改机位的片段，点预览窗口左边的小窗口，就能改为正确的目标机位。

第三步：包装

粗剪完成后要包装，让它看起来更完整、更专业：

  1. 角标 / 人名条（多人对话场景作用特别大）：
    • 左上角文本工具 → 文字模板 → 搜索「人名条」或「角标」；
    • 挑一个模板拖到轨道上，改文字内容，调整位置和大小；
    • 这些模板自带排版动画，只需确定位置即可。
    • 例：画面左下角标「Tim 采访者 / Links 采访者 / Tim Cook 被访者」，观众一眼分清谁是谁。
  2. 金句切片：采访中的精彩金句或独立信息，可以单独提取出来加文字包装，做成小的金句片段——既能突出重点，又很方便传播，这类切片通常点赞很高。

核心三步总结

多机位剪辑听起来复杂，但核心就三步：

  1. 合板对齐
  2. 先剪视频（内容）
  3. 多机位切换

合板保障了时间线统一；先剪单一机位，确保内容一致性；多机位切换让你像导播一样，让画面更丰富、更有质感；最后锦上添花，再做一点包装和调色，你的视频就和别人的不一样了。

这条流程：不管是采访、综艺还是多机位拍摄的活动，其实都够用了。

13 实操：时钟理论与长视频结构

一句话记住：长视频靠分段式剪辑（每段独立打磨成一个小故事）+ 时钟理论（把时长画成圆，在 3/6/9 点位置放爆点）+ 波峰制（平淡→拉升→落下，20 分钟约 10 个波峰）。

从「会用工具」到「会讲故事」

前面已经把常用工具都过完了（基础操作 → 关键帧动画 → 调色 → 抠图 → 跟踪）。工具都会了、素材也拍好了，画面是对的、节奏是顺的——但就是不够出彩。

这就像：你学会了用笔，但不代表能写出好文章；学会了按快门，也不代表一定能拍出好照片。

掌握剪辑工具只是学好剪辑的第一步。

剪辑思维：如何把一个复杂的、混乱的现实世界，讲成一个好的故事。

老规矩：先把成片放进去，一起拉一拉片。

第一步：先给视频长度一个预设

这期节目《熬夜 48 小时，我的身体发生了什么变化》非常复杂——涉及 48 个小时不间断的素材，还有后面大量的采访、调研。最难的一点是怎么分配我们的时间。如果要做这样的视频，先对视频长度有个大概预设：

  1. 13 – 23 分钟（高节奏长视频）
  2. **50 分钟 +**（超长内容）

⚠️ 不建议选中间长度（35 分钟、40 分钟左右）：这个时候正好是一个人处在兴趣衰减期，而视频又没办法在中间拉住所有人——结果就是别人既没完全看进去，又产生了跳出行为，完播率会非常糟糕。

本期选择 19 分 41 秒（高节奏长视频）。所以它对节奏控制非常严谨：不会花大量时间讲一个单一事件，而是更多采用场景化方式，在很小的时间内展示一种情绪和状态，再用旁白把更多信息压缩进更短的时间里——而不是靠更多现场、更冗杂的描述去讲「这里到底是什么现象、发生了什么」。

开头：三个问题就是钩子

开头直接提出三个问题：

  1. 你熬夜吗？
  2. 最长一次熬夜熬过多久？
  3. 熬夜对身体有多大的伤害？

这三问抛出了节目中非常重要的、让观众继续看下去的钩子。

千万不要小看开头短短十几秒，它承担的作用远远比后面的视频都重要。想一想这三个问题的作用是什么——它其实在替观众提问：这些问题可能本身就是观众关心、或被问住的问题，而且确保提出的问题是绝大多数中国人（乃至全世界的人）都会感兴趣的。

所以当问题抛出来，观众会下意识在心里回答「我熬过，我熬过两天」——钩子就已经下完了，观众至少会为这句话留下几秒钟，好奇接下来会发生什么。

紧接着是「我要亲身体验」（这一点很重要）。体验之后进入一段非常快速的混剪：把正片中有张力、后面很痛苦的状态揉在一起；随着不断上升的音乐，配合画面中逐渐扭曲的五官，这段混剪其实在传递一个信息——这个挑战比你想象的要精彩得多。这又构成了一个很明显的钩子：观众本身已经有了问题、看到了后续、也一定程度上预期到痛苦，但不知道会有多痛苦，他一定会想看下去。

所以开头做了三件事：

  1. 抛出问题：让观众产生共鸣和好奇
  2. 揭示主题：告诉观众我们要做什么
  3. 混剪预告：用高密度画面告诉观众，接下来一定有高看的内容

中段：线性叙事 + 大胆砍素材

从这一刻起进入线性叙事：按时间顺序讲述整个故事。

  • 紧接着进入下一个重要议题：留住观众——Tim 的身体细胞活性会不会被保持下来、48 小时后会不会有区别。
  • 讲完后进入一小段现场内容，再进入旁白阶段。
  • 因为前 9 个小时 Tim 本来就是醒着的，观众也不想看他一开始醒着做什么，所以大刀阔斧砍掉巨量内容：10 个小时的视频变成不到 20 秒，直接跳过。

锚点：观众想看的是「变成什么样」

第一次把节奏放缓、加入更多 Tim 现场内容的地方，是在他熬夜到十几个小时、进入第一次疲劳状态的时候。必须清楚——这才是观众想看的东西。

他们想看的是你熬夜之后变成了什么样，不是看你熬夜的过程——这是这个节目的锚点。

所以只保留 Tim 的反应，以及测验体现出智力下降。这和前面学的踩梯子逻辑非常近似：一阶一阶搭观众的预期——观众大概知道 Tim 会变笨，但不会知道会变多笨；带着这个预期，观众会不断想往下看。

因此不断放大 Tim 在疲劳状态下的反应；后面再增添一点现场的慢表述，来稍微舒缓节奏。

波峰制：不能一直紧绷

剪辑有个很重要的点：不能让观众始终保持紧绷的高潮状态——那样视频就等于没有任何高潮。

所以逻辑是不断采用波峰制：平淡一下 → 迅速拉升 → 再降下来，反复循环。一般一个 20 分钟的视频，可能会安排 10 个这样的波峰，来保证观众的兴趣被锁定。

本片的波峰素材来源：

  • 检测活性
  • 智力检测
  • 痛苦反应（多个）
  • 专家采访

（这一段约 7 分钟。）

后端要更快

一般视频后端都不能有慢的剪辑节奏，要比之前更快一些。

所以会看到切镜频率明显拉升；真正开始放缓的地方是从采访开始的（借助动态效果、图片、小的包装）；而最终的结束要快速结束（为了完播率）。

分段式剪辑

剪辑一个长视频时，剪辑师不是一口气从头剪到尾的（否则前后节奏、信息密度容易不均）。

所以长视频需要把时间拆开，分成不同段落，分开剪辑，最后再总装——类似于拼装。

分段式剪辑：每一段都是完全独立剪辑、独立打磨的。

分三段：前期、中期、后期。

结构上，尽量让每一段都有相似的叙事逻辑：

  • 我在干什么？
  • 我的状态怎么样？
  • 中间发生了什么突发状况？
  • 测试数据有什么变化？
  • 并且有哪些东西是无聊的、能不能变成旁白？

这样每一段都是一个完整的小故事，观众看完一段还想看下一段。

好处 1：素材利用率

把素材按阶段归类、筛选时，可以更好地找到最有趣、最有信息量的片段。本质上是——把长视频拆成一个个短视频在看：如果这个短视频有趣，那连在一起就是好几个有趣的短视频。把最有信息量的视频融在每一个阶段里，而不是在几百个视频中大海捞针。（其它视频背后也都是这个逻辑。）

好处 2：解决「下一段放哪、结构怎么排、节奏从哪来」

用音乐来引导：每个段落的音乐完全不一样，一篇会有十几个音乐放在里面。

阶段 音乐情绪
前期 轻松 + 一点好奇
中期 紧张感拉满
后期 疲惫 + 一点挣扎

音乐一变，观众的情绪就会跟着变。所以在粗剪阶段，会先把音乐拖到时间线下面的音频轨道上，一段一段排好，再根据音乐的情绪去大概匹配画面，先找一找感觉。

⚠️ 注意：这里只是找感觉，不是最终版音乐（本质区别）。

时钟理论

如果节奏感通过音乐找到了大概方向，想变得更科学，就用时钟理论：

把视频的时长作为周长画成一个圆，随后标出 0 点、3 点、6 点、9 点的位置。这些位置是观众最容易感到疲惫、想要退出视频的位置——如果这里没有爆点，视频的完播率是没办法保证的。

举例：10 分钟的视频——

  • 3 点 ≈ 第 2–3 分钟：应该是第一个刺激点
  • 6 点 ≈ 第 5 分钟位置
  • 9 点 ≈ 第 7–8 分钟

这些就是刺激点、爆点。

先画一个钟，通过这个钟来避免两种情况：一开始燃了一下，后面整整 10 分钟都是平淡叙事；或者把内容都挤在六点钟。

钟不合适时怎么办：

  • 要么缩减时长，变成更小的钟；
  • 要么把节奏放缓、把高潮点重新分配，确保视频内容充斥整个时钟；
  • 让观众每隔一段时间都能迎来一个新的情绪点。

时钟理论的最大意义：每一阶段都有信息密度的支撑，它能直观地告诉你——在哪个时间点，你缺少了让观众留下的内容。

落地：画好钟、标好节点后，回到时间线，把有张力的镜头、值得讨论的话题、前后可以呼应的画面，均匀地分布在时钟之上，时间线就构建起来了。

反向用法（拆解任何视频）：打开计时器，每 3 分钟记一下——此刻情绪是什么样的、在看什么：0 分钟在想什么、3 分钟在想什么、6 分钟、9 分钟。

如何讲好一个故事：本质上就在时钟的旋转之中——通过分段剪辑不断给观众刺激。不需要每一步都用复杂特效，需要的是在时钟的每一个关键点，给到一个让观众继续看下去的理由。

结语

从操作工具到构思结构的转变，是从剪辑爱好者迈向专业后期最难的一步。

要思考底层逻辑。

14 实操：Vlog 的剪辑结构与色彩

一句话记住：Vlog = 把素材理清楚 → 把结构搭起来 → 把画面调好看；结构靠「思维导图 + 日记」，串联靠「旁白 + 节奏点」。

加州的样片日记，本质是一篇 VLOG——很多平台上特别火的类型。我们去到各种地方，把看到的、听到的、拍到的分享出来，剪辑在一起，就像名字一样，一篇视频化的日记就写完了。

第一步：整理素材

既然是日记，流程就是先把这次旅行中见到的、拍到的素材做对应整理：

  • 分类：视频、图片、音频（最常见的三种）
  • 命名逻辑：自己拍片、自己做 VLOG，一定要做好素材命名 —— 日期 + 地名日记
  • 目录建议：01_素材、02_音乐、03_成片
  • 不同设备拍的画面，可以用时间 + 地点 + 事件来区分，这样后期一眼就能看出这段素材是什么内容
  • ⚠️ 视频文件名不建议更改，保持原始的就可以了

VLOG 的特征与难点

特征：以第一人称视角带着观众一起经历；好处是可以提前定一个大纲，围绕主题去剪辑。

难点：拍摄时有很多不确定，素材之间的内容跳跃性太大——前一秒还在聊巨大的杉树，后一秒就切到路边遇到的人。如果按时间线铺，观众很容易看懵。

技巧：用一个明确的「主线」把素材串起来

  • 初期：列一个无序的思维导图，把素材中的主题内容、以及自己想表达的全部扔上去，然后再排序、构建对应的时间线。
  • 操作：在时间线里整理素材时，想到什么就往上扔——不管是精彩内容还是突然冒出的新主意。这时候完全不用在乎素材怎么排序，只要把素材记录上去就行。
  • 例子：在海边遇到玩滑板很厉害的人，前期随机采访了他们，把素材放进来；然后任何与这个内容有呼应的素材，只要涉及滑板或运动（滑板历史），都放到一起；前后有呼应的部分用箭头简单标注一下——这样就有了完整的素材内容结构。
  • 所有素材都可以被规律化、串联：哪些内容可以放在一起，哪些情绪内容可以形成对比。

思维导图示例（加州样片日记）

通过梳理思维导图，可以把主题清晰标注出来；哪些东西是这个主题的附属品，一定要分类过去。

辅助工具：让大模型帮你写出「日记」

如果你特别健谈、说了很多话，可以用剪映先把视频提取成文字，再把文字全部复制下来，丢给任意一个大模型，让它帮忙总结、重新编排，或者把你的话提取成有意义的内容。

这样就会得到一篇文章——相当于把现场讲的东西做成了一个日记（用来参考），帮助你快速提炼到底发生了什么。因为人是非常健忘的。

思维导图 + 日记：来真正把视频变成可看的状态。

时钟理论（同样适用）

组装：分段式剪辑

剪辑时只需要找到对应素材，继续采用分段式剪辑：只把这一段剪得有趣，再去和前后拼接，这样样片日记就组装出来了。

这样就把生活中线性发生的事件，拆开重组，编织成一个有节奏、有结构的故事。把素材结构梳理完之后，就可以围绕视频主题和分段进行进一步的粗剪和串联。

粗剪：在构建好主题和 A-Roll 时间线后，匹配上对应的 B-Roll 画面。

片段与片段之间的串联（两种过渡）

1. 旁白

  • 两个段落中间，穿插后期录制的、能够承上启下的画外音。
  • 例：从 4:25 开始，从巨杉过渡到第二段场景，就录了一段讲述历史背景的旁白——既丰富了上一段内容，又有了平缓的过渡，观众不会觉得跳脱。

2. 节奏点（高节点）

  • B-Roll 的作用本是解释说明 A-Roll 里提到的内容；但当画面与画面、主题与主题之间需要过渡时，B-Roll 也能发挥重要作用——结合音乐在 Vlog 里做一段小的混剪，进一步提升画面节奏感。

  • 进一步把旁白和节奏点结合起来：可以做「旁白 + 小混剪 + 音乐」。

    先用一段旁白把情绪铺垫好，旁白一停，音乐立刻起来，画面跟着节奏点一起拉升，观众情绪很快被调动起来。这种「旁白收尾 + 节奏点开场」的组合，既能完成过渡，又能给视频情绪起伏（很多纪录片都会用到）。

调色

粗剪完成后就要调色。

  • 灰片：保留大量信息，电影感；
  • 曲线：调成 S 形，增加对比——亮的更亮、暗的更暗；
  • 曲线上往上拖变亮、往下拖变暗，点哪里控制哪里。

批量统一色彩的两个工具：

工具 适用
色彩克隆 很多场景、不同角度的素材需要统一色彩，手动会很繁琐 → 点开后选择已经调好颜色的那一帧
智能调色工具 适合调色初期和快速出片的情况，能给出一个参考效果，帮助建立起调色的方向感

导出与归档

剪辑完成后，先看一眼粗剪效果，就可以进入导出步骤：

  1. 设置好分辨率和码率；
  2. 文件名命名为 demo / 小样，导出到一开始创建的小样文件夹中，方便随时回看和检查问题；
  3. 等所有修改都改好、要给甲方和客户看时，再导出到成品文件夹。

素材、小样、成片在同一个文件夹内，管理起来比较清晰，后期想找也比较方便。

Vlog 的核心

  1. 把素材理清楚
  2. 把结构搭起来
  3. 把画面调好看

剩下的就是多练。每一次拍摄、每一次剪辑，都是经验的积累，慢慢就会找到属于自己的节奏和风格。

附录 D 交付前检查清单

剪辑完成

  • 气口、口癖、重复已清干净，两段气口之间有底噪垫着
  • B-Roll 是否对齐口播节奏；有没有「话没说完就切走」的漏字
  • 同一条片子里没有重复使用同一个 B-Roll
  • B-Roll 轨道音频已关闭
  • 所有音频响度统一，戴耳机听过一遍没有声道问题
  • 字幕：位置在中心下方、字体简约黑体、阴影按 60%/7%/5/-45° 设置
  • 从头播放检查过错别字，字幕已拉长保证收尾衔接
  • BGM 已在字幕之后添加，且收在重拍上
  • 关键帧相关参数的曲线保持一致（缩放 / X / Y）
  • 慢放段落的补帧方式已选好（优先光流法，前提是素材帧率够）
  • 抠像层已用预览轴（S）逐点检查过边缘
  • 调色看过示波器：无过曝、无欠曝、灰/白物体三通道基本重合

导出与交付

  • 分辨率没有超过素材原生分辨率（1080P 不要硬拉 4K）
  • 帧率与原素材一致
  • 码率档位按平台选（抖音/小红书选「推荐」，B 站/YouTube 选「更高」）
  • 封装 MP4/MOV，编码 H.264
  • 音频 AAC 320 kbps / 48000 Hz，导出后试听没有变小、杂音、消失
  • 封面已手动选帧（不是黑场第一帧），有张力、简洁
  • 文件按「日期 + 片名 + 分辨率 + 版本 + 平台」命名
  • 小样进「小样」文件夹，成片进「成片」文件夹

结构复盘（长视频 / Vlog）

  • 时钟上 3 / 6 / 9 点各有一个爆点
  • 每段是否都有相似的叙事小结构（我在干什么 / 状态 / 突发 / 数据变化）
  • 无聊的内容是否转成了旁白
  • 每 3 分钟的情绪起伏记录过一遍
  • 结尾是快速收掉，而不是拖慢
